# Intro_Python_DS
Introductory course to Python for Data Science.

## Data
The exercises in this course use data from WHO which is available from the repository, but can also be downloaded from here:
https://srhdpeuwpubsa.blob.core.windows.net/whdh/COVID/WHO-COVID-19-global-daily-data.csv 

## Environment
This course uses python packages available in the GEODS environment:
https://github.com/anahi-src/geods
